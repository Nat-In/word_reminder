2️⃣ UI Layer - word_window.py - просто интерфейс:
Отдельный файл
class WordWindow(tk.Toplevel): -> получает root как родителя
Этот класс:
- создаёт окно
- создаёт Label
- создаёт кнопки
- настраивает цвет, размеры
- ничего не знает про SQLite
- не знает откуда пришло слово
- не знает что будет дальше
- не знает про 15/15
Он не меняет статус в БД.
Он просто сообщает: “пользователь нажал know”

вызывает callback function
метод: 
def on_know(self):
    self.callback("know")
    self.destroy()
в WordWindow:
self.know_button = tk.Button(
    self,
    text="Know",
    command=self.on_know
)

3️⃣ Controller (state manager)— мозг приложения - в app.py:
class ReminderApp:
- создаёт root = Tk()
- запускает mainloop()
- вызывает get_random_word()
- создаёт WordWindow
- получает сигнал от окна
- меняет статус в БД
- запускает таймер через after()

Он хранит:
-текущее слово
-текущий таймер
-текущее состояние (show / pause)
Он управляет жизненным циклом приложения.
