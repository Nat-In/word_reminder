This project was created while I was learning Python. During my studies, I realized that I lacked technical English vocabulary, which made it difficult to understnd documentation and other IT-related materials.

Intead of using an existing application, I decided to build my own learning tool. This project is both a learning tool and a programming exercise. It allows me to improve my technical English while getting practical experience by building a real Python application.

## Main Idea
The main idea of the project is to help users learn vocabulary through regular exposure rather than traditional memorization.

Instead of waiting for the user to look up words, the application shows a random word at regular intervals while they use their computer. This helps users learn new vocabulary naturally throughout the day without setting aside extra time to study.

The application is not limited to a fixed list of words. User can create their own personal vocabulary by adding new words and their descriptions whenever they come across unfamiliar terms.

## Main Object
The central object of the application is a word.

Every feature in the project is build around creating, storing, displaying and managing words together with their descriptions and learning statuses.

## User Workflow
The user creates and continuously expands a personal vocabulary database by adding new words and their descriptions.

The application periodically displays a random word in a small pop-up window.

For each displayed word, the user can:
- view its description
- mark it as known
- keep it for future review

As the vocabulary database grows, the application becomes more personalized and adapts to the user's learning needs.

## Target Platform
Initial release (V1):
- macOs

Future development:
The application is designed with future cross-platform compatibility in mind.

## Project Scope
Included in V1:
- a simple pop-up reminder window
- random word selection from the personal vocabulary
- displaying word meanings
- managing word learning statuses (know/learn)
- adding new words and their meanings to the vocabulary
- user interaction with the app
- reminder and pause intervals

Out of scope for V1:
- full vocabulary management interface
- search and filtering
- learning statistics
- multi-platform desktop support
- web interfase
- mobile applications
- cloud synchronisation between devices
