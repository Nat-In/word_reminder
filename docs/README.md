# Architecture
## Purpose
This document describes the software architecture of Word Reminder (WRV1).
It defines the main component of the application, their responsibilities and how they interact with each other.

The document also describes the key architectural decisions made during the design of the application. Its purpose is to provide a clear overview of the application's structure and a technical reference during development and future changes to the application (maintenance).
